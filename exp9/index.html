Observing Internet Protocols & DevTools

Experiment 9: Tutorial checklist and interactive live network telemetry simulator.

1. How to Use Browser Developer Tools (Network Tab)

  1. Press F12 or right-click the page and select Inspect to open the Developer Tools pane.
  2. Navigate to the Network tab at the top of the DevTools menu.
  3. Reload the page (Ctrl + R or F5) with the tab open to start capturing assets.
  4. Locate columns for:
    • Name: The asset filename or resource path URL.
    • Status: HTTP Response Status Codes (e.g. 200 OK, 404 Not Found).
    • Protocol: The transport standard used (e.g. h2 for HTTP/2, h3 for HTTP/3, http/1.1).
    • Method: The request method verb (e.g. GET, POST, OPTIONS).
    • Type: Content-Type mime descriptor (e.g. document, stylesheet, script, fetch).
    • Size: Payload transfer volume in bytes (gzipped vs. raw).
    • Time: Complete latency from socket connection to download closure.
