Security Insights: X-Frame-Options & Clickjacking

Many external public servers send the X-Frame-Options: DENY or SAMEORIGIN response header to prevent clickjacking attacks. When a page attempts to embed these sites, the browser blocks the rendering to protect users. For this lab experiment, we target local sub-resources to show iframe targeting safely.
