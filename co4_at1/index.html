Question 1: Interpret the XML Structure (5 Marks)

  • a. Root Element: <courses> (The single top-level parent element).
  • b. Repeating Record Element: <course> (Repeated for each course entity).
  • c. Unique Identifier Attribute: id attribute of <course> (e.g., id="C101").
  • d. Numeric Information Elements: <students> and <credits>.
  • e. Well-Formedness: Yes, the document is well-formed. It contains a single root element, proper nesting, matching tags, quoted attributes, and an XML declaration.
