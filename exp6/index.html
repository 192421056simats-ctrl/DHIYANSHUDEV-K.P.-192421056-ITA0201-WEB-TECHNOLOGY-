Strict XHTML Compliance

This document adheres strictly to the XHTML 1.0 Strict specification.

XHTML Rule Verification Checklist

Rule 1: Element Names Must Be Lowercase ✔ Active

In HTML, tag names are case-insensitive (e.g. <DIV> works). In XHTML, tags must be in lowercase.

<html>, <head>, <body>, <div>, <p>, <span>
Rule 2: All Elements Must Be Closed ✔ Active

In HTML, some elements do not require closing tags (e.g. paragraphs). In XHTML, every element must have a closing tag.

<p>This is a paragraph.</p>
Rule 3: Empty Elements Must Be Self-Closed ✔ Active

Empty tags like line breaks or horizontal lines must be self-closed with a space and a slash.

<br /> and <hr /> and <img src="..." alt="..." />

The horizontal rule above represents a self-closing empty tag: <hr />.

Rule 4: Attribute Values Must Be Quoted ✔ Active

All attribute values must be enclosed in quotation marks. Unquoted values (e.g. class=rule-card) are illegal in XHTML.

class="rule-card" style="color: var(--text-muted);"
Rule 5: Elements Must Be Properly Nested ✔ Active

Tags must be closed in the reverse order they were opened. Nested overlaps like <b><i>bold italic</b></i> are invalid.

Example of valid nesting: underlined italicized text.

<i><u>underlined italicized text</u></i>
