GET and POST Submission Demonstrator

Experimentally observe parameter serialization and transmission security differences.

Observational Objectives

When you click submit on each form below, you will be redirected to the landing page. Check the following:

  • URL Query String: Notice that the GET form appends form parameters to the URL bar (e.g., ?query=val&limit=10), whereas the POST form url remains clean.
  • Payload Volume & Type: GET is limited by URL character length (~2048 chars) and allows binary data only via base64 encoding. POST supports large, multi-part file uploads.
  • Security/Caching: GET forms can be bookmarked and cached, exposing parameters in browser history. POST submissions do not cache parameters and will prompt warning alerts on page refresh.
