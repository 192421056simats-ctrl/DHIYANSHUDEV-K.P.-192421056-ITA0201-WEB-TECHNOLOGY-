🛠️ Developer Tools & Debugging Walkthrough

  1. Open DevTools: Press F12 or Ctrl + Shift + I (Cmd + Option + I on Mac).
  2. Console Tab: View runtime errors, warnings, and execute test expressions live.
  3. Breakpoints: Open the Sources tab, click line numbers in JS files to set breakpoints, and step through code execution (F10 Step Over, F11 Step Into).
  4. Try...Catch Blocks: Wrap suspicious code blocks to gracefully catch and handle exceptions without crashing the script.
